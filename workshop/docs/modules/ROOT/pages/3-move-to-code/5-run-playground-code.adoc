= Run the playground code

[role="_abstract"]
Now that the workbench is set up, you can move your Playground functionality to code.

== Prerequisites

- The Playground code has been exported as described in xref:3-move-to-code/1-playground-to-code.adoc[3.1. Export your playground code].
- A workbench is set up, as described in xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench].

== Procedure

NOTE: If you no longer have the code from step 3.1, re-export it by following xref:3-move-to-code/1-playground-to-code.adoc[Export your playground code].

. Go to your workbench and create a new notebook. Right-click in the file browser and click *New Notebook*. If a modal asks you to select a kernel, click *Select*.
+
image::3-move-to-code/new-notebook.png[Create a new notebook]

. In the first cell, enter the following command and run it:
+
[.console-input]
[source,terminal]
----
!pip install llama-stack-client
----

. Create a second cell and paste the code from the Playground into it. Before you run it, modify the line that sets LLAMA_STACK_URL. Replace that line with:
+
[.console-input]
[source,python]
----
with open("/var/run/secrets/kubernetes.io/serviceaccount/namespace") as f:
    _namespace = f.read().strip()

LLAMA_STACK_URL = f"http://lsd-genai-playground-service.{_namespace}.svc.cluster.local:8321"
----
+
NOTE: This automatically detects your project name from the cluster, so you do not need to edit it.
+
image::3-move-to-code/set-llama-stack-url.png[Notebook Output]

. Run the cell and observe the output.
+
NOTE: This code does not stream, so the response might take a few minutes if you are running on CPU.
+
image::3-move-to-code/notebook-output.png[Notebook Output]

. Save your notebook by pressing *Ctrl+S*, and name it `request-model` when prompted in the modal.
+
image::3-move-to-code/rename-and-save.png[Save the notebook]


== Verification

* After the cell finishes running, you see an answer similar to the answer you got in the Playground.
* From here, you can start modifying the code and integrate it into an AI application.
