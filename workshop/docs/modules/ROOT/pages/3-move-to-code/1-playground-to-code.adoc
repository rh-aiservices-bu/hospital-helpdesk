= Export your playground code

[role="_abstract"]
Before you leave the Playground, extract the code so that you can use it later.

NOTE: This step is optional. You can extract the code again later when you are ready to use it.

== Prerequisites

- The Playground is set up and tested, as described in xref:2-just-a-model/2-playground.adoc[2.2. Chat with your model in the playground]

== Procedure

. If you navigated away from the playground before, make sure to load your prompt again by going Prompt -> Load Prompt inside the Playground. +
You also need to send a message to be able to get the code, you can send this one if you have a blank chat:
+
`A patient just called asking how to get to the radiology department from the main entrance. Can you help me draft a response?`

. Click *View code*.
+
image::3-move-to-code/view-code.png[View code]

. Copy the code.
+
image::3-move-to-code/copy-code.png[Copy code]

. Save the code to a local text file. You will need it in xref:3-move-to-code/5-run-playground-code.adoc[3.5. Run the playground code].

== Next step

To run the code you saved in a coding environment, xref:3-move-to-code/2-workbench.adoc[Create a workbench].
