= Run code in a notebook

NOTE: If you are already familiar with Jupyter, you can xref:3-move-to-code/5-run-playground-code.adoc[skip to the next section].

[role="_abstract"]
A notebook is an environment where you have _cells_ that can display formatted text or code.

This is an empty cell:

image::3-move-to-code/cell.png[Jupyter Cell]

This is a cell with some code:

image::3-move-to-code/cell_code.png[Jupyter Cell Code]

Code cells contain Python code that you can run interactively. You can edit the code and then run it. The code does not run on your computer or in the browser. The code runs directly in your connected environment, *{productname-long}*.

You can run a code cell from the notebook interface or from the keyboard:

* *From the user interface:* Select the cell by clicking inside or next to the cell, and then click *Run* from the toolbar.
+
image::3-move-to-code/run_button.png[Jupyter Run, 100]

* *From the keyboard:* Press *Ctrl+Enter* to run a cell, or press *Shift+Enter* to run the cell and automatically select the next one.

After you run a cell, you can see the result of its code and information about when the code in the cell ran, as shown in this example:

image::3-move-to-code/cell_run.png[Jupyter run cell]

When you save a notebook, the code and the results are saved. You can reopen the notebook to view the results and the code without running it again.

Like a physical notebook, a Jupyter notebook holds your notes alongside your code. You can record notes about your experiments and any parameters you set, and see each cell's output inline. To add notes, switch a cell type from `Code` to `Markdown`.

== Procedure

. In your JupyterLab environment, locate the `0_sandbox.ipynb` file and double-click it to launch the notebook. The notebook opens in a new tab in the content section of the environment.
+
image::3-move-to-code/jupyter-notebook-0.png[Notebook 0]

. Experiment by running the existing cells, adding more cells, and creating functions.
+
Use this notebook as a sandbox to test code and view results without impacting real data.
. Optionally, create a new notebook in which the code cells are run by using a Python 3 kernel:
.. Create a new notebook by either selecting *File > New > Notebook* or by clicking the Python 3 tile in the Notebook section of the launcher window:
+
image::3-move-to-code/new_notebook.png[New notebook, 100]
+
You can use different kernels, with different languages or versions, to run in your notebook.
