= Move to Code

[role="_abstract"]
// Introduction to moving from the playground into code.
So far we have been using the UI Playground to interact with our model. However, as good as that is for testing, it won't deploy any production AI agents for us. To do that, we need to move over to code. +
In this chapter we will explore the code version of what we ran in the Playground. +
Luckily for us, the Playground has easy instructions for how to move our current setup into code.

Start by extracting the code from the Playground in xref:3-move-to-code/1-playground-to-code.adoc[3.1. Playground to Code]
