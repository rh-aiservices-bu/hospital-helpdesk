= Import the {deliverable} files into the JupyterLab environment

:git-version: main

[role="_abstract"]
The JupyterLab environment is web-based, but all operations run on {productname-long} and are backed by the OpenShift cluster. With this configuration, you can run notebooks without installing local tools or consuming local CPU, GPU, or memory resources.

== Prerequisites

- You have created a workbench, as described in xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench].

== Procedure

. In the *Workbenches* tab for your project, click the link for your workbench. If prompted, log in and grant JupyterLab access to your account.
+
image::3-move-to-code/workbench-open.png[Open workbench, 400]
+
Your JupyterLab environment window opens.
+
This file-browser window shows the files and folders that are saved inside your own personal space in {productname-short}.

. Bring the content of this {deliverable} into your JupyterLab environment:

.. On the toolbar, click the *Git Clone* icon:
+
image::3-move-to-code/jupyter-git-icon.png[Git Clone icon, 200]

.. Enter the following Git *https* URL:
+
[.lines_space]
[.console-input]
[source,text]
----
https://github.com/rh-aiservices-bu/hospital-helpdesk.git
----
+
image::3-move-to-code/jupyter-git-modal.png[Git Modal, 200]

.. Select the *Include submodules* option, and then click *Clone*.

.. In the file browser, double-click the newly created *hospital-helpdesk* folder to expand its contents.
+
image::3-move-to-code/jupyter-file-browser.png[Jupyter file browser, 300]


== Verification

. All files related to the {deliverable} are visible.
+
image::3-move-to-code/jupyter-file-browser-2.png[Jupyter file browser]
