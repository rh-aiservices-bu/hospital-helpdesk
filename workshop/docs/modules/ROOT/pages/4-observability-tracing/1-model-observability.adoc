= Monitor your model with metrics

[role="_abstract"]
{productname-short} provides a built-in observability dashboard for viewing model metrics.
Metrics are also scraped and exposed through Prometheus, and can be used to create custom OpenShift dashboards.

== Prerequisites

- You have deployed a model as described in xref:2-just-a-model/1-model-catalog.adoc[2.1. Deploy a model from the model catalog].

== Procedure

. Navigate to the {productname-short} dashboard and select *AI hub > Models*.

. On the *Models* page, click the *Deployments* tab. Verify that you are in the correct project, and then click your deployed model.
+
image::4-observability-tracing/click-model.png[Click the model]

. The following model metrics are displayed:
+
- Requests per 5 minutes
- Average response time
- CPU utilization %
- Memory utilization %
+
image::4-observability-tracing/model-metrics.png[Request per 5 minutes metric]

. To generate more requests, or if none appear within this time period, send a few more messages from the Playground, as described in xref:2-just-a-model/2-playground.adoc[2.2. Chat with your model in the playground].
