= Playground to Code

[role="_abstract"]

Before moving away from the playground, let's make sure to extract the code so we can use it later.

=== Prerequisites

- The Playground is set up and tested, as described in xref:1-just-a-model/3-playground.adoc[1.3. Playground]

=== Procedure

. There is a button in the top right called *View code*, click that. +
If the button is grayed out you need to send a message to the chat, if so you can for example send:
`A patient just called asking how to get to the radiology department from the main entrance. Can you help me draft a response?`
+
image::2-move-to-code/view-code.png[View code]

. Then copy the full code, you can use the copy button in the top left of the modal.
+
image::2-move-to-code/copy-code.png[Copy code]

. Save the code somewhere, you will need it in xref:2-move-to-code/5-run-playground-code.adoc[2.5 Run the Playground Code] where we run it.

=== Next step

Create a Workbench (a coding environment) in xref:2-move-to-code/2-workbench.adoc[2.2 Create a Workbench] so you have somewhere to run the code you just saved.
