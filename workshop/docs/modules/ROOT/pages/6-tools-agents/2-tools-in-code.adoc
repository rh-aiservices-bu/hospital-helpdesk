= Build an agentic workflow

[role="_abstract"]
Earlier, the OGX server ran the agent loop for you. In this section, you run the loop yourself in code with LangGraph, which gives you more control over how the agent tracks state, calls tools, and pauses for human input.

== Prerequisites

- You have deployed the MCP ticketing server as described in xref:6-tools-agents/1-install-mcp.adoc[6.1. Deploy an MCP server].
- You have set up a workbench as described in xref:3-move-to-code/2-workbench.adoc[3.2. Create a workbench].

== Procedure

. Open the notebook `3_tools.ipynb` in your workbench and complete it. Then, continue this tutorial.

== Verification

. At the end of the notebook, you see outputs similar to this.
You can also see the intermediate tool calls the agent makes and which tool it chooses. This is a smaller model, so it might not always choose or interpret the tools correctly.
