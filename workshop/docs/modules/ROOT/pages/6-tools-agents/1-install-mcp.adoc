= Deploy an MCP server

[role="_abstract"]
Before you can use tools in code, you need a tool to call. In this section, you deploy a small *MCP (Model Context Protocol) server* that simulates the IT ticketing system for Oak City General Hospital. Your agent uses this server to read and file tickets.

The MCP server exposes four tools the model can request to use:

- `create_ticket`
- `get_ticket`
- `list_tickets`
- `update_ticket`

The server is pre-seeded with several open tickets you can explore.

The MCP lifecycle operator runs the server for you and verifies that it responds correctly.

== Procedure

Deploy the MCP server in one of the following ways:

* *Using the OpenShift CLI*
+
Run the following command:
+
[source,terminal]
----
oc apply -f https://raw.githubusercontent.com/rh-aiservices-bu/hospital-helpdesk/main/setup/mcp-ticketing-mcpserver.yaml
----

* *Using the OpenShift console*
+
--
. In the {productname-short} dashboard, click the application launcher and then select the *OpenShift Console* option.
+
image::6-tools-agents/ds-project-ocp-link.png[OpenShift Console Link, 600]

. In the OpenShift console, click *+* in the navigation bar, and then click *Import YAML*.
+
image::6-tools-agents/ocp-console-add-icon.png[Add resources Icon]

. Click the arrow next to the project name and select your project from the list.
+
image::6-tools-agents/ocp-console-select-project.png[Select a project, 200]

. Copy and paste the following code into the *Import YAML* editor:
+
[.lines_space]
[.console-input]
[source,yaml]
----
---
apiVersion: mcp.x-k8s.io/v1beta1
kind: MCPServer
metadata:
  name: mcp-ticketing
  annotations:
    mcp.opendatahub.io/catalog-server: mcp-ticketing
    mcp.opendatahub.io/display-name: Hospital IT Ticketing
spec:
  source:
    type: ContainerImage
    containerImage:
      ref: quay.io/rlundber/hospital-helpdesk-mcp-ticketing:0.3
  config:
    port: 8080
    path: /mcp
    env:
      - name: HOST
        value: 0.0.0.0
      - name: PORT
        value: "8080"
  network:
    ingressFrom:
      - namespaceSelector:
          matchLabels:
            kubernetes.io/metadata.name: redhat-ods-applications
        podSelector:
          matchLabels:
            app.kubernetes.io/name: mcp-lifecycle-operator
            control-plane: controller-manager
      - podSelector: {}
  runtime:
    replicas: 1
    resources:
      requests:
        cpu: 100m
        memory: 128Mi
      limits:
        cpu: 500m
        memory: 256Mi
    health:
      readinessProbe:
        tcpSocket:
          port: 8080
        initialDelaySeconds: 5
        periodSeconds: 10
----

. Click *Create*.
--

== Verification

. In the OpenShift console, the `Resources successfully created` message appears, listing `mcp-ticketing`.

. In the {productname-short} dashboard, select *AI hub* -> *MCP servers* and then click *Deployments*. The `Hospital IT Ticketing` server is listed as ready.

image::6-tools-agents/mcp-running.png[MCP Running]
