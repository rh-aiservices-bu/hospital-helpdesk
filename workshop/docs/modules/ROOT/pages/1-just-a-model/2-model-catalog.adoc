= Deploy from Model Catalog

[role="_abstract"]
// Instructions for deploying a model from the model catalog.

Now that you have a project, let's go ahead and deploy a model into it.  

We will deploy a TinyLlama-1.1B model, it's small enough so it can run on CPU, making it great for testing and prototyping (or for demos like this).

=== Procedure

. Navigate to **AI hub** -> **Models** in the left sidebar.

. Search for **TinyLlama-1.1B-Chat-v1.0** in the searchbar and click on the tile that appears.
+
image::1-just-a-model/tinyllama-model-tile.png[Model Tile for Tinyllama]
+
After you have clicked on the tile, you can see the **Model Card** for the TinyLlama model. This contains information such as how it's built, what license it has, and how to use it.

. In the top right of the page you can see a button called Deploy, click that to start the deployment process of our model. It will take you through 3 different pages in the deployment wizard, fill in information accordingly.

. In **Model details**, leave everything as is and checkmark **Use legacy deployment method**.
+
image::1-just-a-model/model-details-form.png[Model Details Form]

. In **Model deployment**:
.. Select your Project (Hospital Helpdesk).
.. Under **Deployment resource**, select **Manual selection** and the runtime **vLLM CPU (x86) ServingRuntime for KServe** from the dropdown.
+
image::1-just-a-model/model-deployment-form.png[Model Deployment Form]

. In **Advanced settings**:
.. Checkmark the **Publish as AI asset endpoint** option (and optionally enter a Use case).
.. Checkmark **Add custom runtime arguments** under Configuration parameters and enter: 
+
`--max-model-len=2000`
.. Checkmark **Add custom runtime environment variables** under Configuration parameters, click **Add variable**, and enter `VLLM_CPU_KVCACHE_SPACE` in the left field and `4` in the right field
.. Leave the rest as is.
+
image::1-just-a-model/advanced-settings-form.png[Advanced Settings Form]

. Finally, review all the information and make sure it looks accurate. If all looks good, then go ahead and click **Deploy model**.
+
image::1-just-a-model/review-form.png[Review Form]

=== Verification

After deploying the model you will automaticalyl be navigated to the model deployments page. The model should get deployed after a few minutes and you will see that it's Ready in the Status column.

image::1-just-a-model/model-ready.png[Model is Ready]
