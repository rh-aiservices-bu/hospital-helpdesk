= Connect to your data

[role="_abstract"]
A data connection is a resource that has the configuration parameters needed to connect to a data source or data sink, such as an AWS S3 object storage bucket. You can connect a data connection to a workbench or a pipeline for easier access to the data source.

For this {deliverable}, you will have two data connections that point to two different S3 buckets:

* *Pipeline Artifacts*: This bucket stores your pipeline artifacts. When you create a pipeline server, you need a pipeline artifacts bucket.
* *Data*: This bucket holds the PDF documents that the pipeline consumes in the RAG section.

NOTE: You can also use storage buckets for storing artifacts such as models. For an example, see the link:https://rh-aiservices-bu.github.io/fraud-detection/fraud-detection-workshop/index.html[Fraud Detection^] {deliverable}.

Choose one of the following options:

* *Use the provided script (recommended):* Runs a script that installs a local S3-compatible storage service and creates the data connections automatically. See xref:1-setup/3-scripted-storage.adoc[Install local object storage with a script].
* *Use your own S3-compatible object storage:* If you already have S3 buckets you want to use, you can create the connections manually. See xref:1-setup/4-manual-storage.adoc[Create connections to your own S3-compatible object storage].
