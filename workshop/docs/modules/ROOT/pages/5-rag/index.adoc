= RAG

[role="_abstract"]
// Introduction to Retrieval-Augmented Generation.


We are now able to talk with our model, see how it responds to different questions, and traceably improve our system. +
However, the model currently only answers based on what it has been trained on, and in a hospital we have many questions that need to be answered from our own internal documents. +
To that end, we want to supply the model with our own documents so it can answer based on them instead. This is where RAG (Retrieval Augmented Generation) comes in.

Let's start by exploring how RAG works in the playground: xref:5-rag/1-rag-in-playground.adoc[5.1. RAG in the Playground]
