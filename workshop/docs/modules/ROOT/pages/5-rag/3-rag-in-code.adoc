= RAG in Code

[role="_abstract"]
// Guide to using RAG from code with MLflow tracing.

Just like before, we could use the Playground's *View Code* button to get a head start, but this time we have prepared a notebook so you can dive straight in without copying and pasting from the Playground.

=== Prerequisites

- Have a workbench set up according to xref:3-move-to-code/2-workbench.adoc[3.2. Create a Workbench]
- Ingested RAG data through either xref:5-rag/2-rag-pipeline.adoc[5.2. RAG Ingestion Pipelines] or xref:5-rag/1-rag-in-playground.adoc[5.1. RAG in the Playground]

=== Procedure

. Navigate to your workbench. If you don't have it open, you can find it through the {productname-short} dashboard -> Projects -> your project (Hospital Helpdesk).

. Inside the workbench, open the notebook `2_rag.ipynb` and run through it. Come back here when you are done.

=== Verification

. At the end of the notebook you should see answers that look something like this:
+
image::5-rag/code-rag-answers.png[Code RAG Answers]

. We now also have MLflow traces to inspect. Navigate to MLflow through {productname-short} -> Develop & Train -> Experiments (MLflow) and open the latest trace. You can see that the model is making tool calls to retrieve the documents we uploaded earlier.
+
image::5-rag/mlflow-rag-trace.png[MLflow RAG Trace]

. You can also use the timeline view to see how long each retrieval step took.
+
image::5-rag/rag-trace-span.png[RAG Trace Span]
