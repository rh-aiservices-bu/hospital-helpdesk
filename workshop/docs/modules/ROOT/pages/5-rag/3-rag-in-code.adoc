= RAG in Code

[role="_abstract"]
// Guide to using RAG from code with MLflow tracing.

Just like before, we can use the Playground View Code button to get a headstart, but this time we have prepared a notebook so that we don't need to go and copy paste from the Playground.

=== Prerequisites

- Have a workbench set up according to xref:3-move-to-code/2-workbench.adoc[3.2. Create a Workbench]
- Ingested RAG data through either xref:5-rag/2-rag-pipeline.adoc[5.2. RAG Ingestion Pipelines] or xref:5-rag/1-rag-in-playground.adoc[5.1. RAG in the Playground]

=== Procedure

. Start by navigating to your workbench. If you don't have it open then you can find it through the {productname-short} dashboard -> Projects -> your project (Hospital Helpdesk).

. Inside the workbench, open up the notebook `2_rag.ipynb` and run through the content, after you are done come back here.

=== Verification

. In the end of the notebook you should get answer that look something like this:
+
image::5-rag/code-rag-answers.png[Code RAG Answers]

. However, we now also have MLflow traces you can inspect. Navigate to MLflow, through {productname-short} -> Develop & Train -> Experiments (MLflow), and look at the latest trace. You can now see that the model is doing tool calls to get the information we uploaded before.
+
image::5-rag/mlflow-rag-trace.png[MLflow RAG Trace]

. You can now also make use of the timeline to see how long each tool request took.
+
image::5-rag/rag-trace-span.png[RAG Trace Span]
