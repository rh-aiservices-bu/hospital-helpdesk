= Playground to Code

[role="_abstract"]

{productname-short} comes with an observability dashboard out-of-the-box which we can use to see some model metrics. +
Many more metrics are also scraped and exposed through Prompetheus, and can be used to create custom OpenShift dashboards.

=== Prerequisites

- A model has been deployed as described in xref:1-just-a-model/2-model-catalog.adoc[1.2. Deploy from Model Catalog]

=== Procedure

. Navigate to the {productname-short} dashboard and go to AI hub -> Models

. When inside the Models page, click on the Deployments tab, make sure you are in the right project, and then click on your deployed model
+
image::3-observability-tracing/click-model.png[Click on the model]

. You will now be able to see a few metrics about the model:
+
- Requests per 5 minutes
- Average response time
- CPU utilization %
- Memory utilization %

image::3-observability-tracing/model-metrics.png[Request per 5 minutes metric]

. If you want to see more requests, or don't see any within this time-period, you can go back to the Playground, as described in xref:1-just-a-model/3-playground.adoc[1.3. Playground] and send a few more messages
