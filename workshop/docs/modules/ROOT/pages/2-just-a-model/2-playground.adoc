= Playground

[role="_abstract"]
// Guide to using the playground.

Now that you have a model deployed, you probably want to use it and make sure that it works.

In {productname-short} there is a *Playground* which allows you to send messages to the model among other things, great for not only making sure that the model works, but to see how it works and how it responds to different messages.

=== Procedure

. Navigate to *Gen AI Studio → Playground* in {productname-short}. Make sure to select your project (Hospital Helpdesk).

. Click *Create Playground*, select our deployed model, and set *Max Tokens* to 1000, and then press Create
+
image::2-just-a-model/create-playground.png[Create Playground]

. After a couple of minutes, you will have the playground ready to use. 

=== Verification

Try writing a few things to it (you can start with a simple Hi) and see how the model behaves. If everything is set up correctly you will get a (hopefully polite) answer back.

Do note that we are using a model running on CPU here, so it might not be the fastest at answering.

[TIP]
====
*Running on CPU?* Responses can take a minute or more. There are two timeouts in the stack that both need to be increased. Open the *OpenShift web terminal* and run:

[source,bash]
----
curl -sO https://raw.githubusercontent.com/rh-aiservices-bu/hospital-helpdesk/main/setup/increase-timeouts.sh && bash increase-timeouts.sh
----

After the script completes, the model has up to 10 minutes to respond without timing out.
====
